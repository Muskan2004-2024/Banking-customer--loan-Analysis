🏦 Banking Loan Analysis | SQL, Excel & Power BI

📌 Project Overview

The Banking Loan Analysis project focuses on analyzing bank loan data to understand lending performance, borrower behavior, loan distribution, and repayment trends. Using SQL, Microsoft Excel, and Power BI, this project transforms raw loan data into meaningful insights through data analysis, KPI tracking, and interactive dashboards.

🎯 Project Objectives
Analyze total loan applications and funded loan amounts.
Monitor loan repayment and collection performance.
Compare good loans and bad loans.
Identify trends in loan applications and borrower profiles.
Evaluate key lending metrics and loan status.
Build an interactive Power BI dashboard to support data-driven decision-making.
🛠️ Tools & Technologies
SQL: Data extraction, filtering, aggregation, and analysis.
Microsoft Excel: Data cleaning, data validation, calculations, and exploratory analysis.
Power BI: Interactive dashboards, KPI cards, charts, and data visualization.

📊 Key Performance Indicators (KPIs)

The project focuses on the following banking loan metrics:

Total Loan Applications: Total number of loan applications received.
Total Funded Amount: Total amount disbursed to borrowers.
Total Amount Received: Total payments received from borrowers.
Average Interest Rate: Average interest rate across loans.
Average Debt-to-Income (DTI) Ratio: Average borrower debt-to-income ratio.
Good Loan vs. Bad Loan Analysis: Comparison of loans based on defined loan-status criteria.
🔍 Analysis Performed
1. Loan Application Analysis
Analyze total applications and monthly trends.
Compare applications by loan purpose, employment status, and other available borrower attributes.
Identify patterns in lending activity.
2. Loan Funding Analysis
Evaluate total funded amounts.
Compare funded amounts across loan categories and borrower segments.
Examine changes in lending activity over time.
3. Loan Repayment Analysis
Analyze the amount received from borrowers.
Compare repayment performance across loan statuses.
Identify loans requiring further monitoring.
4. Good Loan vs. Bad Loan Analysis
Classify loans using clearly defined status criteria.
Compare application counts and loan amounts across categories.
Examine indicators associated with loan risk.
5. Dashboard Development
Create interactive Power BI visuals.
Display key metrics using KPI cards.
Use charts, filters, and slicers to explore loan performance.
Present findings in an accessible format for business users.
📈 Dashboard Highlights

The Power BI dashboard is designed to provide insights into:

Overall loan portfolio performance.
Monthly loan application trends.
Funded and received loan amounts.
Loan status distribution.
Borrower and loan-purpose comparisons.
Good loan and bad loan performance.
